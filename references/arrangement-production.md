# 곡의 역할과 전개 설계

## 한 곡으로 연결하는 순서
목적/감정 곡선 → 리듬·음색·목소리 → 악기 역할 → 구간 변화 → 톤·깊이·전환의 순서로 필요한 판단을 연결한다.
모든 칸을 채우는 것이 목표가 아니다. 고정할 이유가 없는 조성·플러그인 수치·악기는 생략한다.

1. **중심 문장:** 누가/무엇이 전경이며 시작과 끝의 감정이 어떻게 다른지 정한다. 변화 없는 안정도 유효하다.
2. **맥박:** 속도, 강세, 음표 밀도, 스윙/직선/자유 리듬 중 필요한 것을 선택한다. 느린 BPM에서도 세분 리듬은 활발할 수 있다.
3. **화성·음역:** 감정과 주역의 공간을 받친다. 조성은 필요할 때 제안하고 가창 음역을 성별로 자동 단정하지 않는다.
4. **역할:** 주역 1개, 저역의 중심, 반주/질감의 보조를 먼저 정한다. 역할이 겹치면 번갈아 나오거나 음역·길이를 다르게 한다.
5. **구간:** 각 구간마다 유지할 것과 달라질 것, 진입/퇴장, 다음 구간으로 넘기는 신호를 정한다. 변화가 없는 구간도 의도적으로 허용한다.
6. **프로덕션:** 앞의 설계로 해결되지 않는 톤·어택·깊이 문제만 처리한다. 효과를 위한 효과는 넣지 않는다.

## 유형별 골격 — 요청에 맞춰 선택
| 유형 | 계획의 중심 | 전개/끝맺음 | 자동 추가하지 않을 것 |
|---|---|---|---|
| 보컬곡 | 말과 선율, 보컬 음색·발음, 필요한 음역·발성 | 가사 구간/후렴이 있다면 감정 변화와 연결, 악기가 말 사이를 채움 | 무조건 고음 벨팅·보컬 더블·마지막 드럼 |
| 내레이션 BGM | 목소리 뒤의 리듬/화성, 낮은 주목도 | 문장 사이 작은 응답, 내레이션 전경을 계속 비워 둠 | 경쟁하는 리드 선율·보컬·큰 트랜지언트 |
| 감상용 연주곡 | 악기의 선율과 음색이 전경 | 악기 간 주고받기, 음역/동기의 변화 | BGM처럼 무조건 단순화 |
| 루프/미니멀 | 안정된 역할·밀도와 미세 변화 | 끝과 시작의 화성/리듬/잔향 연결, 결론 대신 이어짐 | 피날레·영구적인 악기 추가·페이드아웃 |
| 짧은 음악 | 한 가지 인상과 시간 예산 | 인지 → 짧은 변화 → 정착/컷 대응 | 긴 도입·복수 절/브리지·두 번째 클라이맥스 |
| 자유로운 앰비언트 | 질감·시간감·잔향의 완만한 변화 | 박/마디가 불필요하면 구간 비율 또는 흐름으로 설명 | 비트·후렴·뚜렷한 종지 강제 |

`무보컬`은 노래·허밍·코러스·보컬 찹 등 목소리 질감도 추가하지 않는다는 의미로 우선 해석한다.
사용자가 특정 비언어적 목소리를 함께 요청했다면 가사 보컬과 보컬 소리를 구분해 의도를 확인한다.

## 장르명보다 역할을 먼저
아래는 목적에 따라 선택하는 **음악 설계 아이디어**다. 장르의 정의나 필수 악기 목록이 아니다.

| 원하는 성격 | 주역과 기반의 후보 | 차별화/절제 판단 |
|---|---|---|
| 서정 발라드 | 목소리 또는 피아노 전경, 긴 현악은 뒤 | 같은 멜로디를 계속 겹치기보다 구간별 응답; 고조는 화성/음역으로도 가능 |
| 포크·컨트리의 친밀함 | 어쿠스틱 현의 연주·손의 리듬 | 드럼 없는 추진력도 가능; 공간보다 연주 여백 우선 |
| 재즈의 대화 | 피아노/관악 주역 교대, 베이스와 연주 맥박 | 스윙 강도·악기 상호작용을 결정; 전자 질감은 보조로 둘 수 있음 |
| 록·메탈의 강세 | 기타 어택·리프, 킥과 베이스의 응답 | 기타 거칠기와 목소리 거칠기를 분리; 모든 대역을 포화시키지 않음 |
| 전자·댄스의 추진력 | 신스 모티프, 킥과 저역의 역할 | 정박/브레이크/완만한 맥박 중 선택; 모든 전자음악을 EDM 드롭으로 만들지 않음 |
| R&B·소울의 흐름 | 보컬 프레이징, 유연한 베이스·기타/건반 | 뒤로 놓인 강세나 응답을 필요한 만큼; 보정·딜레이를 기본값으로 강제하지 않음 |
| 힙합의 공간 | 말/리듬 전경, 짧은 동기와 베이스 | 808·보컬 찹은 선택사항; 발음을 가리는 지속 저역 피하기 |
| 시네마틱의 규모 | 넓은 음역의 현악/관악, 느린 화성 또는 동기 | 웅장함과 큰 소리는 다름; 오케스트라 전원이 항상 연주하지 않아도 됨 |
| 특정 지역/전통 색채 | 요청한 악기·연주 방식의 명확한 역할 | 서로 다른 전통을 막연히 섞지 않고 필요한 맥락만 확인 |

## 구간 계획을 쓸 때
작은 표의 열은 `구간 | 감정·밀도 | 악기/보컬의 변화 | 전환·처리`면 충분하다.
시간이 미지정이면 상대 구간이나 마디를 사용하되 총 길이를 확정한 것처럼 말하지 않는다.
클라이맥스가 필요하면 한두 축을 바꾼다: 음역, 하모니, 리듬 밀도, 모티프의 길이, 합주/쉼의 대비. 볼륨 상승이나 새 드럼은 의무가 아니다.
전 구간의 `끝까지 드럼 없음` 같은 조건을 마지막/엔딩에도 다시 대조한다.

시간과 마디를 함께 제시할 때:
- 4/4에서 BPM을 4분음표 기준으로 두면 계획 초 ≈ 마디 수 × 4 × 60 ÷ BPM.
- 박자와 BPM의 박 단위가 다르면 먼저 단위를 명확히 하거나 대략적인 구간 시간만 쓴다.
- 구간 시간 합계와 목표 길이, 도입/여운을 포함하는지 확인한다. 이 계산은 생성기 타이밍의 보증이 아니다.

루프는 시작과 끝의 편성 밀도·베이스 진행·맥박 위치·지속음과 효과 꼬리를 함께 설계한다.
프롬프트는 루프 의도를 전달할 뿐 무봉합 반복을 인증하지 않는다. 실제 경계 편집·청취는 별도 작업이다.

## 톤·타격·깊이
- **저역:** 킥의 순간 어택과 베이스의 지속 몸통을 구분한다. 무거움이 필요해도 두 파트를 항상 길고 크게 두지 않는다.
- **톤:** 주역의 발음/어택을 남기면서 배경의 경쟁을 줄인다. 모든 소스에 동일한 EQ 곡선이나 주파수를 고정하지 않는다.
- **타격:** 강박 앞 여백, 짧은 음가, 일관된 리듬이 먼저다. 압축은 필요한 다이내믹 제어의 후보이지 음질 보증이 아니다.
- **스테레오:** 전경의 위치와 배경의 폭을 나눠 설계한다. 크기를 위해 모든 소스를 최대로 넓히거나 위상 효과를 의무화하지 않는다. 실제 모노 호환성은 생성 후 확인 사항이다.
- **보컬:** 음색·발성·프레이징·발음·필요한 하모니를 연결한다. 자연스러움과 거침의 대상을 명확히 하고, 제공 가사는 편곡에 맞춘다는 이유로 수정하지 않는다.

## 효과는 필요할 때만
추가할 처리마다 `목적 → 대상 → 구간 → 강도`를 연결한다. 강도는 절제/짧게/전경을 가리지 않게 같은 지각적 지시로도 충분하다.

| 선택 후보 | 사용할 이유가 있을 때의 예 | 피할 일괄 처리 |
|---|---|---|
| 리버브/홀/룸/플레이트 | 배경 현악의 깊이, 악기 응답의 짧은 여운 | 전경 목소리를 포함한 전체 믹스에 같은 잔향 |
| 딜레이 | 보컬 문장 끝의 빈 공간만 작은 응답 | 발음 위에 반복음을 계속 겹치기 |
| 압축 | 특정 파트의 튀는 어택을 정돈하면서 호흡 유지 | 전 파트 강압축·클리핑 없는 결과 보장 |
| 포화/왜곡 | 기타 리프의 거친 입자, 신스의 질감 | 모든 목소리와 저역까지 무조건 왜곡 |
| 필터/리버스/라이저 | 실제로 필요한 전환의 짧은 신호 | 모든 구간 끝에 같은 상승 효과 |
| 사이드체인 | 리듬에 맞춰 특정 패드/베이스가 킥의 자리를 양보 | 장르 이름만 보고 믹스 전체 펌핑 |

서로 다른 대상의 드라이/웻 요구는 공존한다. 같은 대상·같은 시점에서만 충돌하는지 확인한다.
목적이 불분명한 효과는 지우고, 필수 조건은 계획과 최종 입력문 양쪽에 남긴다.
