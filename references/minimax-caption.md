# MiniMax용 caption/lyrics 작성 안내

## 지원 범위
음악 스타일과 전개는 `caption`, 가사는 `lyrics`로 나누어 복사하기 좋은 텍스트를 작성한다.
이는 **텍스트 작성 안내**이며 공식 MiniMax API 클라이언트나 특정 모델 버전의 실행 어댑터가 아니다.

먼저 실제 사용하는 UI가 두 텍스트를 받는지 확인한다. 인터페이스나 입력 규격이 다르면 확인된 부분만 맞추고 나머지는 범용 프롬프트로 제공한다.
모델 구현·지원 언어 전체·글자 수 한도·생성 길이 제어를 이 문서만으로 확정하지 않는다. 불명확한 형식만 확인하며 음악 계획 전체를 중단하지 않는다.

## 출력 경로
| 요청 상태 | 출력 |
|---|---|
| 모델 미지정 | 범용 생성 프롬프트. 특정 형식을 강제하지 않음 |
| caption/lyrics 입력이 확인된 보컬곡 + 제공 가사 | caption 블록 + 원문 그대로의 lyrics 블록. 실제 생성은 미검증 |
| 보컬곡 + 새 가사 요청 | 제작 계획에 맞는 caption + 별도 신규 lyrics |
| 보컬곡 + 가사 없음 | caption 초안만 제공, 블록 밖에 **가사 입력 필요** 표시. lyrics에 안내 문장을 넣지 않음 |
| 연주곡/루프 | lyrics 입력 방식이 확인되지 않으면 **범용 프롬프트로 대체**. 빈 문자열/특수 토큰을 임의로 정답 처리하지 않음 |
| 미확인 인터페이스/필드 | 확인된 규격만 변환, 나머지는 범용 텍스트로 제공하고 미확인이라고 표시 |

## caption 설계
다음은 내용을 정리하기 위한 선택형 항목이다. 모델의 필수 스키마나 고정 제목이 아니며, 필요한 요소만 자연스러운 문단으로 연결한다.

| 설계 요소 | 담을 내용 |
|---|---|
| Purpose & Direction | 사용 목적·감정·음악적 성격 |
| Motion & Groove | 필요한 목표 템포/박자·강세·리듬 밀도 |
| Voices & Lyrics | 요청된 음색·발성·발음·하모니, 가사는 별도 입력 |
| Instrument Roles | 주역·반주·저역·배경의 역할 |
| Section Arc | 구간별 진입/퇴장·감정 변화·전환·엔딩 또는 루프 |
| Tone & Space | 효과의 목적·대상·구간·강도와 톤/깊이 |
| Constraints | 전 구간에서 유지할 조건과 피해야 할 요소 |

빈 항목을 채우려고 효과나 악기를 추가하지 않는다. 한국어 해설은 caption 밖에 두고 가사를 caption에 반복하지 않는다.
lyrics 블록은 제공 원문을 보존하거나 명시적으로 새로 요청한 가사만 포함한다.

## 제어와 한계
길이/BPM/공간 지시는 음악적 목표이며 강제 실행 파라미터가 아니다. 정확한 길이·피크/음압·무클리핑을 보장하지 않는다.
미확인 글자 수 제한, 별도 negative 입력, seed/API 파라미터를 생성하지 않는다.
실제 음악 생성 없이 결과가 검증됐다고 말하지 않는다.
