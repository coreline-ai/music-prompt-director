# 느낌을 음악적 결정으로 바꾸기

## 먼저 나눌 것
사용자가 준 **명시 조건**, 문맥에서 읽은 **해석**, 부족한 부분을 채운 **제안값**을 구분한다.
사용자에게는 중요한 것만 짧게 표시한다. 내부 체크리스트를 전부 설문으로 바꾸지 않는다.

| 입력 단서 | 결정할 내용 | 성급히 정하지 않을 것 |
|---|---|---|
| 광고·장면·내레이션·집중 | 전경/배경 역할, 주목도와 편성 밀도 | 장르만으로 목적 대체 |
| 쓸쓸하다가 안도 | 시작 상태와 감정의 도착점 | 무조건 단조→장조 전조 |
| 빠르지만 차분 | 박의 속도와 음표 밀도·어택·강세를 분리 | 빠른 BPM=큰 소리 |
| 여성/남성 음색 | 요청된 음색, 음역·발성·가창 태도 | 성별로 음역·성격·장르 단정 |
| 악기·질감 선호 | 주역/반주/저역/질감 중 역할 배정 | 같은 음역에 모든 악기 겹치기 |
| 빼줘·끝까지·그대로 | 전체/구간/대상별 고정 조건 | 마지막 고조에서 금지 조건 해제 |

모델 이름이나 조성을 모른다는 이유로 멈추지 않는다. 일반적인 용도에서 자연스러운 선택이 있으면 제안값으로 진행한다.
목소리 유무처럼 다른 곡을 만들게 되는 핵심 모호함만 한 번에 최대 2개 묻는다.
`알아서`면 가능한 선택을 공개하고 진행한다. 다만 명시 조건끼리 실제로 양립 불가하면 충돌 지점만 확인한다.
답변 대기 중에는 가정을 확정 사실로 만든 최종 프롬프트를 내지 않는다.

## 다의적인 표현의 선택지 — 제작 제안, 고정 사전 아님
| 표현 | 가능한 수단과 목적 | 피할 자동 치환 |
|---|---|---|
| 웅장 | 넓은 음역의 느린 화성, 큰 편성의 절제된 유니즌, 전후 밀도 대비, 멀리 놓인 잔향층 | 서브베이스 증폭·큰 음압 |
| 따뜻 | 정서적 안도, 둥근 어택의 악기, 부드럽되 말이 들리는 발성, 가까운 소규모 편성 | 무조건 고역 제거·테이프 효과 |
| 타격 | 킥과 베이스 어택의 역할 분담, 쉼표 뒤 강세, 짧은 음의 끝, 리듬 대비 | 모든 트랙을 강하게 압축 |
| 몽환 | 흔들리는 배경 음색, 여백, 반복 모티프의 작은 변형, 느린 공간 변화 | 전 파트에 긴 리버브 |
| 밝고 경쾌 | 가벼운 어택, 상행 모티프, 리듬 빈칸, 적당한 고음역 포인트 | 과도한 고역·빠르기 |
| 고급·세련 | 제한된 음색 팔레트, 일관된 역할, 불필요한 장식 제거 | 장르 라벨만 영어로 늘리기 |
| 꽉 차지만 편안 | 음역별 역할과 지속음/짧은 음의 균형, 필요한 곳만 레이어 | 저역·음압·스테레오를 모두 최대로 |

동일 감정에도 여러 해법이 있다. 현재 목적에 맞는 주된 해법 1개와 보조 수단을 선택하고 이유를 한 문장으로 설명한다.
상충처럼 보이는 표현은 먼저 **대상·구간·차원**이 같은지 확인한다. 조용함은 작은 어택/밀도, 규모감은 배경의 음역/공간으로 공존할 수 있다.
문장 속 `without`, `not`, `slightly`, `only`는 대상까지 함께 읽는다. 효과 이름이 등장했다고 사용 지시로 해석하지 않는다.

## 설계 제안과 실제 제어의 구분
- **설계 제안:** 악기 역할·장르 조합·공간·구간 변화는 목적에 맞춰 선택할 아이디어다. 검증된 프리셋이나 학습된 음악 모델이 아니다.
- **목표값:** BPM·길이·박자 등은 음악적 목표다. 실제 생성 결과와 같은 값이라고 단정하지 않는다.
- **확인된 입력 규격:** 사용자가 쓰는 UI/모델 버전에서 확인 가능한 형식만 변환한다. 불명확한 제어를 발명하지 않는다.

사용자의 현재 요청과 이 스킬의 가이드만으로 설계를 수행한다. 같은 예제를 형용사만 바꿔 재활용하지 않는다.
