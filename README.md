> [!IMPORTANT]
> **Music Prompt Director는 독립적으로 사용할 수 있도록 새롭게 구현한 음악 제작 프롬프트 스킬입니다.**
> 핵심 지침과 가이드가 이 저장소에 들어 있습니다. 별도 데이터셋·음악 라이브러리·서버·실행 스크립트 없이, 스킬을 읽는 AI 에이전트와 함께 사용합니다.

“따뜻하지만 조금 쓸쓸하게”, “웅장하지만 내레이션을 가리지 않게” 같은 일상적인 표현만 전달하세요.
스킬은 그 느낌을 **악기 역할·그루브·보컬·구간 변화·톤과 공간**으로 풀어내고, 음악 생성기에 전달할 입력문으로 정리합니다.

음원을 직접 생성하는 프로그램이 아니라, **무엇을 어떻게 만들지 설계하는 음악 프로듀서형 스킬**입니다.

<a name="quick-start"></a>
## 🚀 빠른 시작

### 1. Codex에 설치하기

Git을 사용할 수 있는 환경에서 다음 명령으로 사용자 스킬 폴더에 복제합니다.
같은 이름의 폴더가 이미 있다면 먼저 내용을 확인하고, 중복 설치하거나 덮어쓰지 마세요.

```bash
mkdir -p "$HOME/.agents/skills"
git clone --branch main https://github.com/coreline-ai/music-prompt-director.git \
  "$HOME/.agents/skills/music-prompt-director"
```

Codex는 사용자 스킬을 `~/.agents/skills`에서 찾습니다. 설치 후 목록에 나타나지 않으면 Codex를 다시 시작하세요. [공식 설치·발견 안내](https://learn.chatgpt.com/docs/build-skills)

### 2. 느낌 한 문장으로 요청하기

```text
$music-prompt-director
비 오는 새벽의 차분한 연주곡이 필요해.
피아노를 중심으로, 마지막에는 작은 안도감이 남게 해줘.
나머지는 알아서 정하고 제작 계획과 복사용 프롬프트를 만들어줘.
```

추가 패키지 설치나 음악 생성 API 키는 스킬 자체에 필요하지 않습니다. 사용하는 AI 에이전트와 음악 생성 서비스의 이용 조건은 별개입니다.

<details>
<summary><strong>📂 설치하지 않고 먼저 살펴보기</strong></summary>

저장소를 원하는 폴더에 복제한 뒤, AI 에이전트에게 다음처럼 요청할 수 있습니다.

```text
이 폴더의 SKILL.md를 읽고 적용해줘.
햇살이 드는 오후 산책을 위한 가벼운 연주곡의 계획과 생성 프롬프트를 만들어줘.
```

파일을 직접 읽어 적용하는 방식과 설치된 스킬의 자동 발견은 다릅니다. 다른 에이전트에서의 자동 설치·호출 호환성은 별도로 확인해야 합니다.

</details>

## ✨ 핵심 기능

| | 기능 | 실제로 하는 일 |
|---|---|---|
| 🧭 | **느낌 해석** | 사용자의 조건·해석·제안값을 구분하고, 중요한 모호함만 최대 2개 질문 |
| 🎹 | **곡 제작 계획** | 장르·박감·주역·반주·저역·보컬을 하나의 목적에 맞게 설계 |
| 🎬 | **구간별 전개** | 감정·밀도·악기 진입과 퇴장·전환·엔딩 또는 루프 연결 구성 |
| 🎛️ | **사운드 방향** | 효과의 목적·대상·구간·강도를 명시하고 불필요한 처리 생략 |
| 📝 | **복사용 프롬프트** | 한국어 설명과 생성 입력문을 분리, 사용자 요청에 따라 언어 조정 |
| 🔁 | **부분 수정** | 바꿔 달라는 요소만 수정하고 합의한 템포·편성·가사 등은 유지 |

### 곡의 목적에 맞는 구조

| 🎤 보컬곡 | 🎻 연주곡·BGM | 🔄 루프·짧은 음악 |
|---|---|---|
| 발성·말맛·하모니와 가사 흐름 | 주역 악기와 배경의 역할 분리 | 반복 경계 또는 짧은 시간 예산 |
| 제공 가사를 임의 변경하지 않음 | 내레이션과 경쟁하는 편성 억제 | 불필요한 후렴·피날레 강제 안 함 |

<a name="workflow"></a>
## 🧩 작동 방식

```mermaid
flowchart LR
    A["느낌·장면"] --> B["의도와 조건"]
    B --> C["곡·구간 설계"]
    C --> D["생성 프롬프트"]
    D --> E["일관성 검수"]
```

**입력은 간단하게, 음악적 판단은 구체적으로.**

- **웅장함**을 저음 증폭만으로 치환하지 않습니다. 음역·편성·공간·구간 대비를 함께 설계합니다.
- **타격감**을 무조건 큰 음압으로 만들지 않습니다. 어택·쉼표·킥과 베이스의 역할을 먼저 정합니다.
- **드라이한 목소리와 큰 홀의 현악**처럼 대상이 다른 처리는 구분합니다.
- **모델을 몰라도** 범용 프롬프트부터 제공합니다. 조성·BPM을 필수 설문으로 요구하지 않습니다.

### 받게 되는 결과

1. **이해한 방향** — 명시 조건과 중요한 가정
2. **제작 계획** — 음악적 선택과 짧은 이유
3. **구간 설계** — 악기·보컬·밀도·전환·처리
4. **생성 프롬프트** — 바로 복사할 별도 입력문
5. **가사** — 제공되었거나 새로 요청한 경우만
6. **검수와 제한** — 보존한 조건, 아직 확인할 사항

핵심 확인이 필요한 요청에는 질문을 먼저 드립니다. 짧은 수정 요청에는 바뀐 부분에 집중합니다.

<a name="examples"></a>
## 💬 이렇게 요청하세요

| 원하는 작업 | 요청 예시 |
|---|---|
| 🎙️ 내레이션 BGM | `웅장하지만 조용한 연주곡. 설명하는 목소리가 잘 들려야 해.` |
| 🌿 자연스러운 보컬곡 | `따뜻한 여성 보컬 포크. 드럼은 끝까지 빼고 기타의 리듬으로 진행해줘.` |
| 🎮 은은한 루프 | `게임에서 반복할 차분한 음악. 마지막에 고조되거나 사라지지 않게 해줘.` |
| ✂️ 짧은 음악 | `앱 시작에 쓸 30초 음악. 한 가지 인상이 남도록 간결하게.` |
| 🎚️ 부분 수정 | `기존 140 BPM과 한국어 보컬은 유지하고 공간감만 줄여줘.` |

<details>
<summary><strong>🎼 예시: 작은 게임 루프를 계획한다면</strong></summary>

**요청:** 종이 인형이 책상 위를 산책하는 게임 배경음. 목소리 없이 작고 장난스럽게.

**설계 방향:** 마림바의 짧은 동기와 낮은 피치카토 응답, 작은 어택과 쉼표로 가벼운 움직임을 표현합니다.

| 구간 | 편곡 |
|---|---|
| 시작 | 짧은 동기와 비어 있는 박 |
| 응답 | 낮은 현이 답하고 주역은 쉼 |
| 변화 | 리듬을 조금 바꾸되 밀도는 유지 |
| 연결 | 처음 화성·맥박으로 이어지며 종결하지 않음 |

이 예시는 설계 방식을 보여 주는 창작 텍스트입니다. 생성된 오디오나 검증된 사운드 프리셋이 아닙니다.
더 자세한 대조 예제는 [예제 가이드](references/examples.md)에서 확인하세요.

</details>

<a name="boundaries"></a>
## 🛡️ 지원 범위와 한계

| 제공하는 것 | 자동으로 하지 않는 것 |
|---|---|
| 모델 중립 음악 설계·범용 생성 프롬프트 | 음원 생성·청취·분석·마스터링 |
| 입력 형식 확인 후 MiniMax용 caption/lyrics 텍스트 구성 | 생성 API 호출·유료 서비스 실행 |
| 사용자 가사 보존·요청 시 신규 가사 작성 | 태그 편집·권리 판정·인터넷 게시 |
| 계획과 프롬프트의 텍스트 일관성 검수 | 정확한 길이·BPM·음압·무클리핑 보장 |

> [!WARNING]
> 스킬의 목표값은 실제 생성 결과의 보증이 아닙니다. 생성 후 길이·가사 전달·루프 연결·피크/클리핑 등을 별도로 확인해야 합니다. 특정 생성기의 공식 인증이나 모든 버전의 호환성을 주장하지 않습니다.

MiniMax 안내는 선택형 **텍스트 작성 가이드**입니다. 실제 UI/모델의 입력 규격이 확인되지 않으면 범용 프롬프트로 대체합니다. [형식·가사 처리 안내](references/minimax-caption.md)

## 🗂️ 저장소 구성

```text
music-prompt-director/
├── SKILL.md                         # 진입점과 공통 흐름
├── README.md                        # 소개·설치·사용 방법
├── .gitignore                       # 로컬·미디어 파일 제외
├── agents/
│   └── openai.yaml                  # 표시 이름·호출 예시
└── references/
    ├── intent-design.md             # 느낌 → 음악적 판단
    ├── arrangement-production.md    # 편곡·보컬·사운드 설계
    ├── output-review.md             # 출력·가사·수정·검수
    ├── minimax-caption.md           # 선택형 입력 작성 안내
    └── examples.md                  # 창작 대조 예제
```

`references/`는 스킬 내부의 동작 가이드입니다. 필요한 문서만 읽도록 구성되어 있습니다.
